# Responsible use

- Access public pages only and respect website terms, robots guidance, rate limits, and reasonable request pacing.
- Do not authenticate, submit forms, bypass controls, or collect customer submissions.
- Treat captured API keys, nonces, session parameters, and map tokens as sensitive third-party material even when exposed publicly; redact them from reports.
- Store only form definitions and fields, never entered values.
- Do not republish bulk scraped descriptions, promotions, jobs, raw HTML, business contacts, coordinates, or identifiers without a rights and privacy review.
- Keep generated datasets private by default and preserve provenance.
- Do not invent relationships or fill unknown values from assumptions.
- Use opt-in live smoke tests; normal automated tests should use local fixtures.
